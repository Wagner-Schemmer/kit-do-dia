# ☀️ Kit do Dia

Pomodoro com ciclos, lista de tarefas, conversores e bloco de notas. Tudo salvo no navegador (`localStorage`).

## Ferramentas
1. **Pomodoro** — foco 25 / pausas 5 e 15, ciclo de 4, alerta sonoro (WebAudio), contador do dia
2. **Tarefas** — adicionar, concluir, filtros (todas/pendentes/feitas)
3. **Conversores** — moeda BRL→USD (cotação editável), temperatura (°C→°F/K), km→mi, kg→lb
4. **Notas** — auto-save + download `.txt`

## Rodar
Go Live no VSCode ou `python3 -m http.server` na pasta. Sem build, sem dependências.
